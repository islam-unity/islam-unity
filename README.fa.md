## 🌙 درباره پروژه

**اتحاد اسلامی** یک پلتفرم جامع و اوپن سورس اسلامی است که معارف سنتی اسلامی — شامل قرآن کریم، احادیث، تفاسیر و فقه — را با فناوری نوین هوش مصنوعی ترکیب می‌کند. مأموریت ما دسترسی‌پذیر کردن معارف اصیل اسلامی برای همگان در سراسر جهان، از طریق ابزارهای هوشمند و تجربه کاربری زیبا است.

چه طالب علم باشید، چه محقق یا پژوهشگر و چه صرفاً کنجکاو، اتحاد اسلامی منابع و دستیار هوش مصنوعی لازم برای تعمیق فهم شما از اسلام را فراهم می‌کند.

## 🛠️ فناوری‌ها

| لایه | فناوری‌ها |
|------|----------|
| **بک‌اند** | Python 3.11+, FastAPI, SQLAlchemy 2.0, aiosqlite, asyncpg, Pydantic v2 |
| **پنل مدیریت** | Vanilla JS (ES2022)، CSS Custom Properties، طراحی RTL-first |
| **موبایل** | Flutter 3.x / Dart، shared_preferences، flutter_markdown |
| **هوش مصنوعی / یادگیری ماشین** | DeepSeek, NVIDIA NIM, معماری چند ارائه‌دهنده LLM, پایگاه داده برداری Qdrant |
| **زیرساخت** | Docker, Docker Compose, uvicorn, WebSockets, SSE |
| **احراز هویت** | JWT (PyJWT), bcrypt, OTP پیامکی (ملی پیامک) |

## 🚀 شروع سریع

### پیش‌نیازها

- Python 3.11+
- Flutter 3.x SDK
- Git

### ۱. کلون کردن مخزن

</div>

```bash
git clone https://github.com/YOUR_USERNAME/islam-unity.git
cd islam-unity
```

<div dir="rtl">

### ۲. راه‌اندازی بک‌اند

</div>

```bash
cd backend

# ایجاد و فعال‌سازی محیط مجازی
python -m venv venv

# ویندوز
venv\Scripts\activate
# مک / لینوکس
# source venv/bin/activate

# نصب وابستگی‌ها
pip install -r requirements.txt

# کپی و پیکربندی متغیرهای محیطی
cp .env.example .env
# فایل .env را با تنظیمات خود ویرایش کنید (کلیدهای API، آدرس دیتابیس و...)

# اجرای سرور
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

<div dir="rtl">

### ۳. راه‌اندازی اپلیکیشن Flutter

</div>

```bash
cd flutter_app

# دریافت وابستگی‌ها
flutter pub get

# اجرا روی دستگاه یا شبیه‌ساز متصل
flutter run
```

<div dir="rtl">

### ۴. دسترسی به پنل مدیریت

مرورگر خود را باز کنید و به آدرس زیر بروید:

</div>

```
http://localhost:8000/admin/
```

## 🔗 مروری بر API

بک‌اند اتحاد اسلامی بیش از **۴۶ اندپوینت RESTful** را در حوزه‌های زیر ارائه می‌دهد:

| حوزه | مسیر | توضیحات |
|------|------|---------|
| **احراز هویت** | `/api/v1/auth/*` | ثبت‌نام، ورود، OTP پیامکی، توکن JWT |
| **قرآن** | `/api/v1/quran/*` | سوره‌ها، آیات، جستجو، تدبر، قاریان |
| **کتابخانه** | `/api/v1/library/*` | کتب، فصول، قطعات، جستجوی RAG |
| **چت AI** | `/api/v1/ai/*` | جلسات چت، پاسخ‌های جریانی، ردیابی توکن |
| **مشاوره** | `/api/v1/consultation/*` | پیام‌رسانی با علما، مدیریت رشته‌ها |
| **فید** | `/api/v1/feed/*` | فید پرسش و پاسخ دانش |
| **ذکر** | `/api/v1/dhikr/*` | ردیابی ذکر و آمار روزانه |
| **نماز** | `/api/v1/prayer/*` | اوقات شرعی بر اساس موقعیت |
| **توسعه‌دهندگان** | `/api/v1/developer/*` | کلیدهای API، آمار استفاده، مستندات |
| **مدیریت** | `/api/v1/admin/*` | عملیات CRUD کامل مدیریتی |
| **وب‌سوکت** | `/ws/*` | جریان بلادرنگ چت AI |

> 📝 **مستندات تعاملی API** در آدرس‌های `http://localhost:8000/docs` (رابط Swagger) و `http://localhost:8000/redoc` (ReDoc) هنگام اجرای سرور در دسترس هستند.
